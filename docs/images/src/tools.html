TOOL 1 · AGOV.COST

Cost estimator

In: model, input and output tokens

Out: price for the call, plus a budget warning

TOOL 2 · AGOV.LOGGER

Action logger

In: each agent action, who asked, what changed

Out: a JSONL audit log you can query and summarize

TOOL 3 · AGOV.POLICY

Policy checker

In: an action and a JSON policy file

Out: allow, needs approval, or deny, with a reason

Standard library only. No setup, no accounts, no network. Run them from tools/ today.
