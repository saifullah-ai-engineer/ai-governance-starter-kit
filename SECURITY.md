# Security Policy

## Reporting a vulnerability

If you find a security problem in this project, please report it privately. Email the maintainers at the address listed in the repository, or open a private security advisory on the repository if one is available.

Please include:

- What you found and where
- Steps to reproduce the problem, if you can share them safely
- What you think the impact could be

Do not open a public issue for a vulnerability, and do not share details publicly until the maintainers have had time to fix it. We will confirm receipt and keep you updated on the fix.

## What these tools do and do not do

The templates and tools in this project are planning and record keeping aids. They never send your data anywhere. They make no network calls, they upload nothing, and they do not talk to any model provider on their own.

Any API keys, tokens, or credentials you use with your own AI tools stay local to your own systems. This project never asks for them, never stores them, and never transmits them.

## Supported versions

Security fixes are made on the latest release. If you are using an older version, please update before reporting a problem that may already be fixed.
